# ABRXOS Transcriber v1

Local-first word-level transcription for ABRXOS on macOS Apple Silicon.

Current capabilities:
- Whisper MLX Turbo
- Word-level timestamps
- transcript.json and transcript.txt
- JSONL Worker
- Tauri Studio

Roadmap:
1. PLAN.json
2. Alignment Review
3. SOURCE_ALIGNMENT.json
4. Geometra bridge
5. Cutter bridge
6. VideoFlow adapter
